# Arnav Kamdi | AI & Technology Portfolio

A responsive React + Vite portfolio using a premium white-and-electric-blue visual system.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local address shown in your terminal.
4. Run `npm run build` to create a production build in `dist/`.

## Personalize before publishing

- Replace `public/arnav-profile.jpg` if you want to use another photograph.
- Review the project descriptions in `src/main.jsx`; update technical details, status, screenshots, and outcomes to match the real implementation.
- Verify internship dates and completion status.
- Update or remove the email address if needed.
- The floating portfolio assistant is a local demo with predefined answers. It does **not** call a live AI model. To make it a true AI assistant, connect it to a server-side endpoint and keep provider API keys out of frontend code.
- Add verified certificates and achievements when available.

## Deploy

This is a Vite static frontend and can be deployed to Cloudflare Pages or Vercel. Build command: `npm run build`; output directory: `dist`. A production AI assistant would need a secure backend/serverless function in addition to the static site.


## Internship certificate
The Maincrafts Technology AI/ML internship certificate is stored at `public/maincrafts-internship-certificate.png` and displayed in the Achievements & Certifications section. Visitors can open or download it from the page.
